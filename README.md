# SOC_control

> ⚠️ 名稱備註：本專案 repo 名為 `SOC_control`，但實際內容是 **SOFC（固態氧化物燃料電池）高溫升溫控制**，與電池 SOC（State of Charge，充電狀態）無關。

# SOFC 高溫燃料電池 — 動態升溫決策系統 · 操作手冊

## 1. 系統概述
本工具是一個 **Streamlit 互動式網頁應用**，協助工程師在 SOFC（固態氧化物燃料電池）**升溫啟動階段**做即時的氫氣／空氣流量決策。

系統針對**尾燃器（After-burner）加熱迴路**設計，透過三個關鍵溫度的熱連鎖控制，在「追蹤目標升溫速率」與「保護電堆熱應力」之間取得平衡：

| 代號 | 量測點 |
| :--- | :--- |
| **TC1** | 尾燃器出口溫度 |
| **TC3** | 電堆陰極出口溫度 |
| **T2**  | 電堆陰極入口溫度 |

採用**「自適應黑盒子模型 (Adaptive Black-box Model)」**：不依賴完整理論模型，而是比較前後兩次採樣的實際溫度變化，動態推估升溫速率並給出下一步流量建議。

---

## 2. 核心演算法

### A. 升溫速率追蹤（氫氣調整）
以前後兩筆採樣的陰極出口溫度差，計算實際升溫速率，再依與目標速率的誤差調整氫氣流量：

```
實際升溫速率 = (TC3_now − TC3_last) / Δt(分鐘)
速率誤差     = 目標速率 − 實際升溫速率
氫氣調整量   = 速率誤差 / H2_GAIN        （H2_GAIN = 0.20 ℃/min per lpm，由實驗數據初步擬合）
建議氫氣     = max(0, 目前氫氣 + 氫氣調整量)
```

### B. 熱應力安全保護（空氣調整）
模型內建兩道安全連鎖，**會覆寫上面的氫氣建議以保護設備**：

1. **🚨 尾燃器溫差保護**：當 `TC1 − TC3` 接近上限（預設 170 ℃）時，強制將氫氣壓低 5%、空氣 +50 lpm。
2. **⚠️ 電堆溫差保護**：當 `|TC3 − T2|` 接近上限（預設 100 ℃）時，空氣 +100 lpm，使電堆溫度更均勻。

最終空氣建議不會低於設定的「空氣最小流量」。

## 3. 安裝與啟動

需要 Python 3。建議使用虛擬環境：

```bash
cd SOC_control
python3 -m venv .venv
.venv/bin/python -m pip install -r Requirements.txt
.venv/bin/python -m streamlit run app.py
```

啟動後瀏覽器會自動開啟 `http://localhost:8501`。

**依賴套件**（見 `Requirements.txt`）：`streamlit`、`pandas`、`numpy`、`plotly`

## 4. 操作流程

> **重要：本工具需要連續輸入「至少兩次」才會給出建議。**
> 因為建議是基於前後兩筆數據的溫度變化計算的，第一次送出僅作為基準記錄。

1. **左側邊欄 — 設定邊界條件**
   - 目標升溫速率（℃/min，預設 0.7）
   - 電堆出入口最大溫差 `|TC3−T2|`（預設 100 ℃）
   - 尾燃器與陰極最大溫差 `TC1−TC3`（預設 170 ℃）
   - 空氣最小流量（預設 500 lpm）
   - 邊界條件的任何變動會自動記錄在「📜 邊界變動歷史」。

2. **中間表單 — 輸入當前系統狀態**
   填入現場讀數：氫氣流量、空氣流量、T2、TC3、TC1、陽極壓力、陰極壓力，按 **「⚖️ 執行模型診斷並獲取建議」**。

3. **第一次送出** → 系統記錄為基準（不給建議）。

4. **第二次（及之後）送出** → 系統輸出：
   - 🎯 **氫氣流量建議**（含與目前值的增減）
   - 🎯 **空氣流量建議**
   - 📈 **當前升溫速率**
   - 觸發安全保護時會以紅色警示顯示原因。

系統僅保留最近 20 筆歷史紀錄。

## 5. 參數定義 (Data Dictionary)

### 側邊欄（邊界條件）
| 變數 | 說明 | 預設值 |
| :--- | :--- | :--- |
| `target_slope`  | 目標升溫速率 | 0.7 ℃/min |
| `max_stack_dt`  | 電堆出入口最大溫差 \|TC3−T2\| | 100 ℃ |
| `max_ab_dt`     | 尾燃器與陰極最大溫差 TC1−TC3 | 170 ℃ |
| `min_air_flow`  | 空氣最小流量 | 500 lpm |

### 輸入區（當前狀態）
| 變數 | 說明 | 預設值 |
| :--- | :--- | :--- |
| `in_h2`  | 燃料氫氣流量 | 10.0 lpm |
| `in_air` | 空氣流量 | 800.0 lpm |
| `in_t2`  | 電堆陰極入口 T2 | 300.0 ℃ |
| `in_tc3` | 電堆陰極出口 TC3 | 280.0 ℃ |
| `in_tc1` | 尾燃器出口 TC1 | 430.0 ℃ |
| `in_pa`  | 陽極壓力 | 1.0 kPa |
| `in_pc`  | 陰極壓力 | 2.0 kPa |

---

## 6. 注意事項
- 本工具的建議值基於**黑盒子模型動態擬合**，`H2_GAIN` 等增益係數由初步實驗數據擬合而得，僅供參考。
- **實際操作務必以現場安全狀況與標準作業程序為準。**
